# Como jogar o jogo
O jogo deve ser aberto com um servidor para que ele possa se tornar um jogo multiplayer entre duas pessoas que estão na mesma rede.
Assim que uma pessoa iniciar o jogo com o seu servidor, a outra pessoa terá que dar um duplo-clique no HTML para que possa entrar na página e, dentro da página do jogo, deve digitar o código do servidor que foi iniciado do outro jogador para que ambos possam jogar juntos. Assim que os dois jogadores estiverem online, irá aparecer dois tanques com o nome de cada jogador em cima deles.
O objetivo do jogo é matar o tanque inimigo. Para mover o seu tanque, deve-se utilizar as setas direita, esquerda, cima e baixo e, para atirar, deve-se pressionar a tecla de espaço.
